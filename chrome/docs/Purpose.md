# Purpose of these documents

Preserve the extension-specific facts that would otherwise require another investigation: how
Chrome request interception reaches the Tor WebAssembly client, which traffic is covered, and
how to test without changing a personal browser profile. Keep the browser and Windows application
roles distinct.

Documentation is useful when a later contributor can apply a verified lesson directly. Source
inspection, upstream documentation, and executed tests are different evidence; identify which
supports a claim. Link to general product documentation instead of copying it.

Maintain this topic library as behavior changes. Session context and lessons about how a decision
was reached belong in `Walkthrough`, with links to the stable explanation here.
