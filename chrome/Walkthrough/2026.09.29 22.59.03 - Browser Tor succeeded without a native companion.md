# Browser Tor without a native companion

TorVpnForWindows remains the Windows system tunnel. This separate Chrome subproject now contains
an experimental JavaScript extension with bundled tor-js/Arti WebAssembly, connect/disconnect,
new connection, and Turkish/English interface. The user asked to keep its documentation here and
preferred using only an extension over a local helper. The initial companion implementation was
removed after browser execution succeeded.

A real headless Chrome extension and a normal HTTPS tab both returned `IsTor: true`. Interception
worked with a blocking profile proxy while the offscreen engine reached the public demonstration
gateway over WebRTC. An initial transport-policy test failed after navigation; enabling the page
and runtime domains and testing the new document resolved it. The final integration checks also
passed engine-stop request blocking, proxy restoration, and bootstrap cancellation.

The implementation is an HTTP browsing subset with a demonstration gateway, not the Windows
program's country/bridge controls or system tunnel. See [BrowserIntegration](../docs/BrowserIntegration.md)
and the [user guide](../README.md) before changing traffic handling. No personal Chrome profile was
used for testing, and the extension has not been loaded into the user's regular browser.
