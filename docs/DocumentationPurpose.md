# Why project knowledge is preserved

This application combines routing, Windows filtering, Tor control and transport processes.
Its previous failures depend on the interaction of these parts, rather than on general API
usage. The lessons in `LESSONS.md` preserve those causes and working solutions so a later
change can use the same evidence without repeating the original investigation.

Keep durable contracts and verified methods in the topic documents. Keep dated context and
approach-changing observations in Walkthrough. Git already records file changes; neither
documentation collection should retell that history. The index points readers to the relevant
knowledge without requiring every document to be read.
