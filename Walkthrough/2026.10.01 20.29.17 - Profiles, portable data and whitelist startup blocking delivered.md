TorVpnForWindows now has named settings profiles, a protected Default profile, individual resets and compact two-row profile controls. Personal bridge lines remain intact during resets. Portable user data, settings recovery and complete exception logging were delivered in 1.5.1; their contracts are in the [configuration](../README.md#configuration) and [portable storage document](../docs/PortableData.md).

The user reported that Internet Indicator stayed green while Tor connected. The active profile used the tunnel whitelist, and the indicator was outside its three listed programs. The existing guard blocked only those listed programs before the tunnel opened. The saved whitelist mode had been retained during migration; this correction does not change the user's list entries or selected mode.

Version 1.5.2 adds a baseline block for all normal traffic while connecting. Whitelist application blocks outrank the direct permit, which exists only while the tunnel is open. Closing the tunnel removes that direct permit before removing tunnel permits. The runtime log records the baseline block at 20:22:12, the tunnel permit opening at 20:22:21, and the Connected state immediately afterward.

The installed executable was updated and started. Both signed executables, the tools bundle and signature trust archive are published in [v1.5.2](https://github.com/muhammetozeski/TorVpnForWindows/releases/tag/v1.5.2). Source changes are on master. Existing LESSONS.md and troubleshooting documents remain the sources for their established subjects; the documentation index and Walkthrough guide supply the maintenance entry points.
