# Project guidance

Before changing code, read [the documentation guide](docs/DocumentationGuide.md) and
[the index](docs/README.md), then follow links relevant to the task. Preserve verified,
reusable lessons as part of the work; update the existing source of knowledge instead of
duplicating it. Keep temporary output under ignored `build/`.

When taking over the project, use [the Walkthrough guide](Walkthrough/Walkthrough-Rehberi.md).
Select records by their filenames; read the latest context and relevant experience.
Record meaningful results in a new dated file. The minimal-reading objective applies only
to Walkthrough, not to other development work.
